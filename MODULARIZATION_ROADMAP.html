Step-by-Step Tab-Based Modularization (Zero-Risk & Crash-Free Architecture)
Production Safe
🎯 Goal & Core Objective

Currently, admin.html (6,400+ lines) and admin.js (21,000+ lines) are large monolithic files. Every time an agent or developer edits a single tab, reading thousands of lines is slow and consumes excessive context tokens.

Solution: Safely split the project tab-by-tab into small, modular files (e.g. components/tabs/paisa/paisa.html ~300 lines) so changes happen in seconds with zero crash risk on GitHub Pages.

🎨 Uniform Tab Design Principle (Golden Rule)

Har modular tab me uniform structure follow hoga:

  • Root Wrapper Card: Tab ka poora content ek single main wrapper card (e.g. <div class="tab-card-wrapper"> ya <div class="form-container">) ke andar encapsulated hoga. Koi bhi loose elements bahar nahi honge.
  • Standard Header Strip: Card ke top par uniform Header Bar (Title, Icon, Subtitle, aur Primary Actions like Add/Filter/Export).
  • Consistent Styling & CSS: Har tab ka apna dedicated CSS (e.g. components/tabs/<tab>/<tab>.css) rahega jisme consistent padding, rounded corners (16px/20px), soft border/shadows aur theme support hoga.
