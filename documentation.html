1. Executive Summary & Practice Mission

CaseBook is a digital legal enterprise platform engineered specifically for Indian advocates, chambers, and litigation practices. It streamlines the day-to-day lifecycle of litigation — from case registration and judicial order tracking to automated daily cause list generation, hearing notifications via WhatsApp, court staff management, task checklists, and khata expense management.

Unlike generic software, CaseBook is structured around authentic Indian procedural law, providing tailored dynamic fields for Civil Suits, Criminal Cases, State/Police Matters, Family Law, Revenue Matters, Miscellaneous Petitions, and Criminal Complaints.

Multi-Jurisdiction Filing

Tailored legal registers for Civil, Criminal, State, Revenue, Family, and Complaint cases with Indian statutory acts.

Daily Cause List Board

Dynamic court appearance board filtered by date and court. Instant A4 print-ready output with advocate signature blocks.

Accounts & Khata Ledger

Tracks client fee receipts, court work expenses (certified copies, stamps, clerkage), net savings margin, and WhatsApp closing.

Offline-First Cloud Sync

Operates uninterrupted offline via Service Worker and SafeStorage, with two-way cloud sync to Supabase PostgreSQL.

2. Architecture & Technical Foundations

CaseBook is designed with a zero-build-step, modular vanilla web architecture. This guarantees maximum longevity, zero framework rot, blazing-fast load times under 100ms, and complete offline autonomy.

Layer Technologies & Components Purpose & Characteristics
Frontend Shell HTML5 Semantic, CSS3 Custom Properties, Tailwind Utilities Zero build step, theme engine (Azure, Midnight, Judicial, Forest), mobile-first responsive layout down to 320px screens.
Service Modules ES6 Modules (app-core.js, case-service.js, hearing-service.js, calendar-service.js, task-service.js) Clean separation of concerns with global backward-compatibility bindings for HTML onclick handlers.
Custom UI Helpers mint-datepicker.js Custom in-app Monday-first date picker replacing inconsistent OS controls. Z-index 1000005 for guaranteed modal priority.
Offline Resilience safeStorage abstraction, Service Worker (sw.js) Transparent fallback: localStorage → sessionStorage → in-memory fallback. Complete offline caching.
Cloud Backend Supabase (PostgreSQL 15), Row Level Security (RLS) Multi-table normalized schema with triggers for auto-updating timestamps, UUID primary keys, and real-time syncing.

3. User Roles & Access Hierarchy

CaseBook strictly separates administrative chamber management from public/client case tracking:

1. Admin Console (Chambers Advocate & Staff) Full read/write/delete privileges across all cases, hearing forward dates, courts directory, financial ledger, and cloud synchronization. Access is guarded by credentials session storage and PIN tokens.
2. Client Guest Tracking Portal Read-only public portal allowing litigants and clients to look up next hearing dates, court venues, and case status using either their Case Number or Mobile Number. Confidential chamber notes, finances, and deletion actions are strictly concealed.

4. Operational Guide by Module

4.1 Home Dashboard & Practice Analytics

The Home Dashboard serves as the morning command center. It summarizes practice health with live KPI counters:

  • Total Active Matters: Overall pending litigation across all jurisdictions.
  • Listed Today: Real-time count of cases listed on the current calendar date across all courts.
  • Listed This Week: Upcoming hearings scheduled over the next 7 days.
  • Disposed / Decided: Historical archive of completed matters.

4.2 Dynamic Case Registration

Case registration dynamically adapts its input fields based on the selected Case Category:

  • Civil Cases: Plaintiff vs Defendant, Suit Value (₹), Court Fees paid, Act & Section (CPC, Specific Relief, Succession), Process Stage.
  • Criminal Cases: State/Complainant vs Accused, Police Station, Crime/FIR Number, Penal Sections (BNS / IPC, CrPC / BNSS, NDPS, POCSO), Bail Status & Surety.
  • Family Disputes: Petitioner vs Respondent, Marriage Date, Conciliation / Mediation Stage, Maintenance orders.
  • Revenue Cases: Land village, Khasra/Gata Number, Revenue Board / Sub-Divisional Magistrate (SDM) / Tehsildar forum.

4.3 My Cases & Case Registry

The Registry houses the master case inventory with real-time multi-parameter filtering:

Instant Filter → Court & Type Filter → Case Dossier Card → Client WhatsApp Notice

4.4 Daily Cause List & Appearance Board

Generates the daily court board for the advocate and junior team. Features include:

  • Appearance Date Selector: Select any date using the custom calendar or quick preset pills (Today, Tomorrow, In 2 Days, Next Week).
  • Court Filter: Filter the day's cause list by specific court or view consolidated chambers list.
  • Print Daily Cause List: Generates a formal, standardized A4 printable document with advocate seal and signature block.
  • WhatsApp Summary: Compiles and sends a structured briefing of the day's listed matters to chambers WhatsApp groups.

4.5 Court Hearing Calendar & Forward Dates

Visual monthly grid with appearance counts per day. Clicking any date reveals all scheduled matters. The Forward Dates tab allows one-click date assignment:

  • Enter Case Number or select from auto-complete list.
  • Select the next hearing date and the next judicial stage (e.g. Evidence, Arguments, Framing of Issues, Order).
  • Record judicial remarks and automatically update the case record, historical hearing timeline, and next cause list.

4.6 Chambers Accounts & Expense Manager

A purpose-built legal accounting module tracking daily client receipts and disbursements:

Nature Description & Typical Categories Financial Effect
Work + Expense Client fee received plus associated court work expenditure (certified copies, stamps, clerkage, typing). Inflow (+) and Outflow (-); calculates exact Net Chamber Savings (Profit) live.
Direct Client Fee Pure advocate professional consultation fees, brief retention, or appearance fee. 100% Inflow (+); increments chamber net savings directly.
Chamber Expense General practice overheads: chamber tea, stationery, photostat paper, process fees. 100% Outflow (-); deducted from net earnings.

Features dual view modes (Visual Cards with financial breakdown and Spreadsheet Table view), CSV Export, A4 Printable Khata Ledger, and Daily Closing on WhatsApp.

4.7 Court & Staff Directory

Manages judicial establishments (District Courts, Commercial Courts, Family Courts, High Court Benches) and court staff contacts (Readers, Ahlmads, Peons, Munshis) with phone dialers and WhatsApp integration.

4.8 Task Deadlines & To-Do Board

Tracks urgent legal filing deadlines, limitation dates, affidavit preparations, and certified copy follow-ups. Includes priority tagging (High, Medium, Normal) and checklist sub-steps.

4.9 Case Transfer Management

Maintains an immutable audit trail when cases are transferred between courts, benches, or districts. Supports single-case transfers and bulk batch migrations.

4.10 Supabase Cloud Synchronization

Provides seamless two-way data replication between local chamber devices and the secure Supabase cloud database. Displays live connection badges (🟢 Local & Cloud Ready) and provides one-click manual synchronization.

6. Security, Backups & Maintenance

Recommended Daily Practice Routine
  1. Morning: Open My Cause List → Print / Save PDF of the day's court appearance board.
  2. During Court Hours: Record certified copy expenses, stamps, and fee receipts in Accounts.
  3. Evening: Open Forward Dates to log the next hearing dates; click Daily Closing on WhatsApp to review the day's financial summary.
  4. Weekly: Open DB Manager → export CSV backup of cases and accounts ledger.
